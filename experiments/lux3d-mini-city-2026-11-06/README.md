# Lux3D 微缩城市沙盘试验（2026-11-06）

## 结论

Lux3D 本身是 3D 资产生成工具，不是地图渲染器。参考图的「移轴微缩城市」效果由三部分组成：

1. **Lux3D 图生 3D**：把一张鸟瞰参考图生成可旋转的微缩城市沙盘模型（GLB + PBR 贴图）。
2. **Blender**：导入模型，补沙盘底座、暖色三点布光、长焦斜俯视相机与浅景深。
3. **后期**：提高饱和度、暖色偏移、上下渐变移轴虚化、轻微泛光与暗角。

本次验证说明：单张参考图可以生成可用的城市沙盘资产，但密集多建筑场景会被合并成一个网格，建筑细节和地理关系是近似重建，适合风格探索，不适合要求准确还原地图的用途。

## 已知限制

- 单图生成的模型是融合网格，不保留独立建筑对象；若要逐栋编辑或做玩法地图，需要按建筑/街区拆分多次生成。
- 本次没有启用四视图增强，也没有使用多视角一致性校准。
- 移轴虚化是屏幕空间后期，不是真实镜头倾斜；Blender 相机已带景深，后期再做渐变模糊。
- 参考图为新加坡滨海中心一带的城市鸟瞰，生成结果只保留相似的体量与配色关系，不是地理准确模型。

## 如果要继续

- **更接近参考图**：把城市拆成地标塔楼、裙楼、连廊、道路和绿化等 3–5 类资产分别生成，Blender 按地图布局摆放。
- **要游戏内可交互地图**：在 Unity/Three.js 中只导入低模 LOD，移轴效果用后处理实现；Lux3D 只负责有辨识度的单体资产。
- **只要宣传图**：直接在当前 `.blend` 上换相机角度、调景深和灯光，比重新生成模型更快。
