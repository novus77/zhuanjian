# 转间 Roomturn

第一人称 3D 观察解谜游戏 · 群核科技 Aholo 全球 3D AI 黑客松参赛作品。

**你是一个发条小人，在一间老房子里醒来。按 ← → 让自己原地转身 90°，世界在眼里转过一个方向，但房间本身不动。靠观察、靠换个方向看，把三间房里的秘密找出来，才能回家。**

## 核心机制

**旋转的是人，不是房间。**

- 按 **← / →**：发条小人原地转身 90°（共 4 个朝向）
- 房间、家具、光、重力**全都不动**
- 鼠标环视只能看前方 ±60°，**看不到身后**，想看身后必须转身
- 第一人称，没有第三人称模式

| 操作 | 键位 |
|---|---|
| 移动 | WASD |
| 转身 90° | ← / → |
| 环视 | 鼠标移动（点击画面锁定，Esc 释放） |
| 互动 | E |
| 重置 | R |

## 三关设定

同一栋老房子、同一个黄昏、同一扇窗、同一棵树、同一个家庭的三段记忆。

| | 第 1 关 书房 | 第 2 关 卧室 | 第 3 关 儿童房 |
|---|---|---|---|
| 年代 | 1930s | 1970s | 2000s |
| 尺寸 | 9.6×6.4×4.6 m | 9.0×6.0×4.4 m | 10.4×7.0×4.8 m |
| 日落时刻 | 黄昏开始 | 黄昏中段 | 黄昏末尾 → 入夜 |
| 窗外那棵树 | 刚栽的梧桐，细枝 | 长到窗框高 | 粗壮，秋天半秃 |
| 核心谜题 | 门楣符号刻在门**外侧**，要站对方向、抬头看气窗里的走廊镜子才读得到 | 光从西窗经衣柜镜门折到床底，**只有站在床侧面向衣柜**才看得见光路 | 娃娃屋转盘把手每转 90° 换一侧，**必须绕桌子走**；最后拉灯绳让太阳落山 |
| 主色 | 胡桃木深棕 + 墨绿 | 奶油白 + 浅粉 | 天蓝 + 星星黄 |

## 技术栈

- **前端**：Vite + TypeScript + Three.js
- **3D 渲染**：`@manycore/aholo-viewer`（支持 Mesh + 3DGS，WebGL2）— 正式版接入
- **音频**：Web Audio API（空间音频 + 多轨音乐）
- **Aholo 资产管线**：
  - **SpatialGen**：生成 3 个房间的空壳（墙面、地板、窗、氛围）
  - **Lux3D**：生成全部家具与道具（GLB）
  - **Lux3D image-to-3D**：用儿童房照片生成娃娃屋
- **部署**：静态站点
