# 转间 · M1 灰盒

《转间》的 M1 机制原型：第一人称探索 + 按 V 切换第三人称左右旋转房间，验证“双视角 → 旋转 → 门对齐 → 走出去”的核心手感。

## 运行

```bash
npm install
npm run dev
```

打开：http://127.0.0.1:5173/

## 操作

| 操作 | 键位 |
|---|---|
| 移动 | WASD |
| 切换第一/第三人称 | V |
| 左右旋转房间（任何视角） | ← / → |
| 互动 / 开门 | E |
| 重置 | R |
| 环视房间 | 鼠标移动（点击开始自动锁定；Esc 释放；不支持时按住左键拖动） |

**目标**：把东墙上的门转到北侧，靠近后按 E 开门。

## 当前包含

- 7.5×4.9×4.2 矩形灰盒房间 + 固定底座/方位标记
- 第一人称相机（发条小人碰撞体，模型不显示）
- 第三人称相机 + 可见发条小人模型
- 第一/第三人称双视角切换
- 左右 90° 旋转（Y 轴，任何视角）
- 门对齐检测 + 开门 + 通关提示
- 程序化占位音效（齿轮、木头、落定、开门）
- 调试手柄 `window.__zhuanjian`
