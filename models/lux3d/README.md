# Lux3D 资产生效规范

每个资产使用独立目录 `<ID>/`（例如 `S03/`、`C01/`），固定结构如下：

```text
<ID>/
├── README.md          资产卡：来源、状态、尺寸、任务 ID、已知问题
├── source/            Lux3D 原始输出（GLB / ZIP），保持原文件名，不编辑
├── work/              Blender 工作文件
│   └── scripts/       该资产专用的检查、整理、导出脚本
├── export/            Unity 导入用 FBX 与独立纹理
├── inspection/        检查报告、真实渲染预览
└── records/           任务状态、报价、交付清单等 JSON
```

## 命名与边界

- 资产 ID 使用文档中的 `S01–S09`、`B01–B10`、`C01–C07` 编号。
- 原始 Lux3D 文件名保留原样；导出文件名以资产 ID 前缀开头，例如 `S03DeskChair.fbx`。
- `source/` 中的原始文件不改名、不覆盖；清理后的模型放 `work/` 或 `export/`。
- 交付预览页统一放 `models/lux3d/_deliveries/<ID>-v<版本>/`，不塞回资产工作目录。
- 未提交的报价、review 和 journal 放 `models/lux3d/_plans/<ID>/`。
