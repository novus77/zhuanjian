# B03 梳妆台装饰

包含两个独立 Lux3D 外观件，桌体/抽屉/镜面由 Blender/Unity 制作。

## B03-L 雕花桌腿

- 任务：`4828539`，20 积分
- 三角面：12828；尺寸 0.209 × 0.226 × 0.720 m
- 文件：`source/B03DressingTableLeg_glb.glb`、`work/B03DressingTableLeg_clean.blend`、`export/B03DressingTableLeg.fbx`
- 设计：浅胡桃木弯腿，膝部叶饰；一个源件复用四条。

## B03-M 椭圆镜框

- 任务：`4828544`，20 积分
- 三角面：22544；尺寸 0.691 × 0.029 × 0.820 m
- 文件：`source/B03OvalMirrorFrame_glb.glb`、`work/B03OvalMirrorFrame_clean.blend`、`export/B03OvalMirrorFrame.fbx`
- 设计：浅胡桃木椭圆镜框、Art Nouveau 植物边缘；镜面为独立平面，由 Unity 做反射。
