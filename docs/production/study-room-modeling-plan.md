# 第一关书房：整屋模型制作计划

更新：2026-11-06。依据：用户确认先完成整间书房模型，再集中接入 Unity 和浏览器；Lux3D 采用累计 500 积分自动执行预算，额度内不逐件询问费用。

## 1. 本轮交付边界

先完成第一关，不提前生成第二、三关的专用家具。保留现有 Unity/Web 灰盒作为尺度、观察视线和机关行程的依据，本轮不逐件替换浏览器场景。

统一方向为英式复古老宅结构与克制的新艺术植物装饰。深胡桃木、旧黄铜、橄榄绿软包、米白灯罩/陶瓷为主，不增加互相冲突的家具年代和材质。

整屋基准为 **9 × 7 × 3.2 m 净空间**，角色眼高 1.4 m；四扇门、气窗及走廊观察镜保持已验证的坐标关系。参考图中的旧尺寸不覆盖当前灰盒。

## 4. 执行顺序

1. 下载并检查 S04、S07、S08、S09，保留原始产物与任务编号；局部问题优先本地修正。
2. 完成 S06 台灯清理/分件、S02 书桌装配和现有 S01/S03/S05 的整屋摆放准备。
3. 基于同一布局搭建建筑、书柜、壁炉、四门和软装，添加准确的线索小物。
4. 在 Blender 中装配整间书房，统一朝向、单位、原点、材质和命名；按角色尺度验证视线与通路。
5. 输出整屋透视、玩家眼高、多角度和机关局部图，修正穿插与不合理连接。
6. 整屋模型达到下列验收要求后，再集中接入 Unity、配置碰撞/交互/灯光并更新 Web 构建。

## 5. 模型阶段验收

- 一个可继续编辑、资源打包的整屋 `.blend`，规则结构与生成道具分组保存；需要动作的对象不融合进静态网格。
- 家具与地面/台面真实接触；门、抽屉和主要玩家通路无穿插；比例以现有灰盒为准。
- 保留角色眼高与四个观察位置的视图，不能用俯视参考图代替实际观察验证。
- 书脊线索、钥匙和照片有明确位置，装饰不遮挡线索；太阳门与其他三门维持玩法关系。
- 整屋导出和独立资产导出可重新导入；贴图不依赖绝对路径或 Blender 程序节点在 Unity 自动还原。
- 明确哪些视图是 Blender 模型效果、哪些是 Unity 实际运行；本轮整屋模型尚未完成前不宣称浏览器已达到最终美术。
