## 一、三套方案总览

| | 方案 A《三代人的房间》 | 方案 B《房子的三种职能》 | 方案 C《记忆的三种状态》 |
|---|---|---|---|
| 核心思路 | 每一关是**一个真实年代**的房间 | 每一关是**一种房间功能**，时代虚化 | 每一关是**记忆的一种状态**（清醒/模糊/鲜活） |
| 三个房间 | 1930s 书房 / 1970s 卧室 / 2000s 儿童房 | 工作间 / 休息室 / 玩耍间 | 褪色 / 漂浮 / 饱和 |
| 情感强度 | ★★★★★ | ★★★ | ★★★★（但偏怪诞） |
| 视觉差异 | 大（三种年代三种色） | 小（同一套语言） | 最大（超现实） |
| 资产复用 | 低 | 高（省 30–40% 工作量） | 中 |
| Aholo 展示效果 | 好（三种风格、prompt 差异大） | 一般 | 很好（但难控） |
| 制作风险 | 中 | 低 | 高 |
| 适合谁 | 想要记忆感、想在预告片里做出"三个时代" | 想稳、想省工作量 | 想要创新性 20% 打满 |

**我的建议：方案 A 为主线，从方案 C 借一个元素放到第 3 关**（见文末"推荐组合"）。

## 二、方案 A《三代人的房间》（推荐）

一个家庭、三代人、三个年代。三个房间共用世界观，但风格完全不同——玩家进每一关都有"换了一个时代"的感觉。

### A-1 第 1 关 · 爷爷的书房（1930s 沿海城市）

**一句话**：一间被夕阳晒了几十年的老书房，空气里全是旧纸和樟木的味道。

| 项 | 内容 |
|---|---|
| 尺寸 | 7.5 × 4.9 × 4.2 m |
| 色调 | 胡桃木深棕 + 墨绿 + 黄铜 + 旧纸米色 |
| 光 | 夕阳从西窗斜射进来，光柱里有灰尘 |
| 关键家具 | 顶天立地胡桃木书架、大书桌 + 抽屉、藤椅、绿罩黄铜台灯、留声机（大喇叭）、玻璃书柜、老式座钟、地球仪、砚台 + 毛笔、卷轴画、雕花木窗、藤编地毯 |
| 门的符号 | 写在四扇门的门楣上：太阳 / 月亮 / 星星 / 钥匙 |
| 旋转机关 | 书架上有 12 本书，书脊拼起来是一句话；**只有把房间转到某个角度，夕阳才正好扫过这些书脊**，字迹才显出来 |
| 解谜 | ① 转到正确角度，让夕阳照亮书脊，读出"太阳落山前要回家"→ ② 得知该开太阳门 → ③ 抽屉被锁，钥匙藏在留声机喇叭里 → ④ 开门离开 |
| 秘密 | 错误角度时，镜子照出书架上爷爷写的一行小字 |
| 3D 资产重点 | 留声机（喇叭是视觉主角）、座钟、地球仪、玻璃书柜 |
| 记忆点（预告片） | 房间一转，夕阳扫过整面书架，灰尘炸开 |
| SpatialGen prompt | `1930 年代中国沿海城市的旧书房，胡桃木护墙板与顶天立地书架，绿罩黄铜台灯，西窗斜射的夕阳，光柱里的灰尘，微缩模型质感，无人物` |
| Lux3D 资产 | 留声机、老式座钟、地球仪、藤椅、砚台、毛笔、卷轴、玻璃书柜门 |

### A-2 第 2 关 · 妈妈的卧室（1970s–80s）

**一句话**：妈妈少女时代的房间，干净、克制，藏着一点没说出口的心事。

| 项 | 内容 |
|---|---|
| 尺寸 | 7.0 × 4.6 × 4.0 m |
| 色调 | 奶油白 + 浅粉 + 木色 + 月光冷白 |
| 光 | 月光从薄纱窗帘透进来，冷白偏蓝 |
| 关键家具 | 白漆铁艺床、碎花被面、木衣柜（门内嵌穿衣镜）、蝴蝶牌缝纫机、梳妆台 + 圆镜、竹壳热水瓶、搪瓷杯、双卡录音机、明星海报、薄纱窗帘、木地板 |
| 门的符号 | 门框上的木雕花纹：四种花样 |
| 旋转机关 | **月光 → 穿衣镜 → 床底** 的三段反射：必须把房间转到让月光先照到柜门上的镜子，再折到床底，才看得见床下的铁皮饼干盒 |
| 解谜 | ① 找到光路，转房间让月光打到镜子上 → ② 床底亮起来，出现铁皮盒 → ③ 盒里有钥匙和一封没寄出的信 → ④ 打开衣柜后的暗门离开 |
| 秘密 | 录音机按下播放键，会放出八音盒旋律（妈妈小时候的曲子，和第 3 关是同一首） |
| 3D 资产重点 | 缝纫机、梳妆台圆镜、录音机、铁皮饼干盒、热水瓶 |
| 记忆点（预告片） | 房间一转，月光像水一样从窗帘流到镜子上 |
| SpatialGen prompt | `1970 年代中国家庭少女卧室，白漆铁艺床、碎花被面、木衣柜、缝纫机、梳妆台圆镜、薄纱窗帘透进的月光，安静、怀旧、微缩模型质感，无人物` |
| Lux3D 资产 | 缝纫机、梳妆台、圆镜、录音机、热水瓶、搪瓷杯、铁皮盒、明星海报（贴图） |

### A-3 第 3 关 · 我的儿童房（2000s）

**一句话**：二十年前自己的房间，星星夜光贴还在天花板上发微光。

| 项 | 内容 |
|---|---|
| 尺寸 | 8.0 × 5.2 × 4.4 m |
| 色调 | 天蓝 + 米黄 + 星星暖黄 + 原木色 |
| 光 | 白天是暖日光，入夜后星星夜光贴和星星灯是唯一光源 |
| 关键家具 | 星星夜光贴（天花板）、小床、玩具箱、书桌、小霸王游戏机、大富翁、书包、奖状、小书架、地毯、星星灯、**娃娃屋（核心道具）** |
| 门的符号 | 贴纸：太阳 / 月亮 / 星星 / 彩虹 |
| 旋转机关 | **大房间 + 娃娃屋双层转盘**：大房间转到太阳方向时，光从大窗进；娃娃屋要自己再转，才能接住光点亮小灯 |
| 解谜 | ① 太阳光点亮娃娃屋小灯 → ② 月光点亮大灯 → ③ 两灯都亮，封死的门打开 → ④ 拉远镜头，发现这间房也是架子上的娃娃屋 |
| 秘密 | 娃娃屋的窗里有一个和你一样的小人；抽屉里有一张更小的拍立得，照片里是玩家 |
| 3D 资产重点 | 娃娃屋（Lux3D image-to-3D）、玩具箱、游戏机、星星灯、夜光贴 |
| 记忆点（预告片） | 镜头穿过窗户，一路拉远，发现整间房只是一个娃娃屋 |
| SpatialGen prompt | `2000 年代中国儿童房，星星夜光贴天花板、小床、玩具箱、小书桌、暖日光、木质地板、温暖略带童话感、微缩模型质感，无人物` |
| Lux3D 资产 | 娃娃屋外壳、玩具箱、游戏机、书包、星星灯、奖状（贴图）、夜光贴（贴图/自发光） |

## 三、方案 B《房子的三种职能》（稳妥、省工作量）

不强调年代，只强调**房间的用途**，三个房间用同一套美术语言，看起来像同一个娃娃屋的三个房间。

- **第 1 关 · 书斋**：书架 + 书桌 + 台灯，主色胡桃木 + 墨绿；机关是"书脊拼字"。
- **第 2 关 · 卧房**：床 + 衣柜 + 梳妆台，主色奶油白 + 浅木；机关是"月光三段反射"。
- **第 3 关 · 玩具房**：玩具箱 + 娃娃屋 + 矮桌，主色米黄 + 星星黄；机关是"双层转盘 + 光线"。

**共同点**：同样的门框、窗框、踢脚线、地板材质、灯光设置；家具造型语言统一（圆角、黄铜五金）。

| 优点 | 缺点 |
|---|---|
| 资产复用率高，省 30–40% 工作量 | 三个房间容易"看起来差不多"，预告片记忆点弱 |
| 美术风格统一，好控制质量 | "三代人"的情感叙事会变淡 |
| 风险最低，适合时间紧 | Aholo 展示的"三种风格"效果打折 |

## 四、方案 C《记忆的三种状态》（最有创意、风险最高）

三个房间是**同一种记忆的三种状态**，不是三个年代。

- **第 1 关 · 清醒的记忆**：房间整齐、颜色褪成灰绿，所有东西像蒙了一层灰；机关是"整理"——把转乱的物件归位。
- **第 2 关 · 模糊的记忆**：房间一半是实体、一半是半透明残影，家具漂浮、比例不对；机关是"对齐"——旋转房间让残影重叠成完整形状。
- **第 3 关 · 鲜活的记忆**：颜色最饱和，娃娃屋真的在动，墙上的画会变；机关是"嵌套"——大房间和娃娃屋互相映射。

| 优点 | 缺点 |
|---|---|
| 视觉最独特，创新性 20% 容易打满 | 制作难度最高，做不好会变成"看着乱" |
| 和"房子记性坏了"的设定最贴 | 需要大量特效（半透明、漂浮、残影），网页端性能风险 |
| 传播性可能最好 | 和"温暖怀旧"的基调有冲突，容易滑向诡异 |

## 五、推荐组合（我的建议）

**主结构用方案 A，第 3 关借方案 C 的一个元素。**

| 关卡 | 采用 |
|---|---|
| 第 1 关 | A-1 爷爷的书房（1930s），完整采用 |
| 第 2 关 | A-2 妈妈的卧室（1970s），完整采用 |
| 第 3 关 | A-3 我的儿童房（2000s）+ **C 的"娃娃屋是活的"设定**（娃娃屋的窗会自己亮、小人会动），作为全片高潮 |

理由：

1. 三关三种年代，**预告片一眼看出"这是个跨越三代人的游戏"**，情绪线最清楚。
2. 三个房间的 Aholo prompt 差异大，正好展示生成能力的宽度。
3. 第 3 关加"活的娃娃屋"，把方案 C 的创意点收进来，但只做一个房间，风险可控。
4. 资产虽然不能复用，但黑客松正好需要"看得出做了很多"。

## 六、需要你拍板的三件事

1. **选哪套？** A / B / C / 推荐组合。
2. **三关的顺序**：现在是 书房 → 卧室 → 儿童房（年代由远及近）。要不要倒过来（从自己的房间开始回忆）？
3. **第 2 关的情感浓度**：是"干净克制、只留一点暗示"，还是"更明确地讲妈妈的故事（信、照片、录音机）"？
