## 1. 三间房的整体关系（先定骨架）

### 1.1 三间房是同一栋房子的三代人

不是三个不同的房子，是**同一栋老房子在不同年代的样子**。所以三间房要有"同一个骨架"的感觉：

- **同一扇窗，同一棵树**：三间房的窗都在**西墙偏北**，窗外**只有一棵树**，什么别的都没有。三个年代的差别只在树本身——爷爷年代是一棵刚栽下的小梧桐，妈妈年代它长到窗框那么高、枝叶伸进画面，我的年代它已经很粗、被修剪过、秋天落了半树叶子。
- **同一个黄昏**：三关发生在**同一天的同一个黄昏**，太阳正在落山。所以三关的光都是低角度的暖橙色斜光，只是太阳越来越低（见 1.4）。
- **同一个墙角**：北墙东角，三代人都在那里放过东西——爷爷放樟木箱、妈妈放五斗橱、我放玩具箱。玩家如果留意，会发现"同一个角落"。
- **同一块地板**：木地板的花纹走向一致，只是磨损程度不同（爷爷年代最旧，我的年代最新）。
- **同一个后期**：三关统一使用微缩模型后期（轻移轴模糊 + 暖色 LUT + 暗角 + 灰尘粒子），保证三关看起来是同一个世界。
- **同一扇门的位置**：东墙正中，三代人都是从这里进出。

**这个设计的价值**：玩家玩到第三关时会隐约觉得"我来过这里"。不需要台词，靠空间记忆。

### 1.2 三个贯穿全片的物件

| 物件 | 第 1 关 | 第 2 关 | 第 3 关 |
|---|---|---|---|
| **八音盒旋律** | 留声机里放着同一首曲子（78 转唱片） | 录音机按键能放出同一首（磁带） | 娃娃屋里的八音盒就是这首（原版） |
| **黄铜钥匙** | 开书桌抽屉 | 开衣柜暗门 | 开娃娃屋抽屉 |
| **拍立得** | 爷爷拍的（太阳门开着） | 妈妈拍的（床底的光） | 我拍的（娃娃屋，角落有影子） |

三个物件形成"同一件事被三代人各自记住一遍"的结构。

### 1.3 每一关的旋转承担不同的叙事功能

| | 旋转在玩法上 | 旋转在叙事上 |
|---|---|---|
| 第 1 关 | 让黄昏的光照到书脊 | **时间**——太阳落山前要回家 |
| 第 2 关 | 让最后一缕夕阳经镜子折到床底 | **秘密**——有些事要换个角度才看得见 |
| 第 3 关 | 让光进入娃娃屋点亮双灯 | **传承**——把光传下去 |

### 1.4 同一场黄昏：三关是同一天日落前的十几分钟

这是本次深化最重要的统一设定。三关不是三个不同的天气，而是**同一个黄昏的三个时刻**：

| 关 | 时间 | 太阳位置 | 光 | 窗外那棵树 |
|---|---|---|---|---|
| 第 1 关 书房 | 黄昏开始 | 还有一点高度 | 黄金时刻，暖橙斜光，光柱清晰 | 刚栽的小梧桐，细枝 |
| 第 2 关 卧室 | 黄昏中段 | 几乎贴地 | 极低角度的橙红斜光，长影子 | 长到窗框高，枝叶伸进画面 |
| 第 3 关 儿童房 | 黄昏末尾 → 入夜 | 落山 | 橙光变冷变蓝，最后一缕天光；入夜后出现月光 | 已很粗，秋天落叶，半树光秃 |

**为什么这样统一**：

1. 三关的窗是同一扇窗，树是同一棵树，光是同一束光——玩家不需要被告知，自然感到"这是同一个地方"。
2. "太阳落山"成为全片的时间线：爷爷说"太阳落山前要回家"，第 1 关黄昏开始，第 3 关太阳真的落山了。**玩家的三关，就走完了一个黄昏。**
3. 三关都由"低角度光"驱动谜题，机制一致，只是复杂度递增（直射 → 经镜子 → 进娃娃屋）。
4. 视觉上三关都偏暖橙，不做纯冷色夜戏，画面更统一、也更好看。

**入夜是玩家手动触发的**（第 3 关）：房间里有一根灯绳，拉一下，太阳就落山了——天光变蓝，月亮上来。这一下是整个游戏的情感转折点，必须由玩家亲手拉。

### 2.1 空间布局

  阳光→ │        ［大书桌］［藤椅］         │ （太阳门）

        │ ［留声机］      ［座钟］          │
        └──────────────────────────────┘
                    S（南）

| 区 | 位置 | 内容 |
|---|---|---|
| **工作区** | 房间中央偏东南 | 大书桌（1.5×0.8×0.78 m）+ 藤椅 + 绿罩黄铜台灯 + 砚台 + 毛笔 + 一叠信纸 |
| **藏书区** | 北墙整面 | 顶天立地胡桃木书架（4.2 m 宽 × 2.6 m 高，10 格）+ 玻璃书柜（0.9 m 宽，双开门） |
| **会客角** | 西南角 | 留声机（落地式，大铜喇叭）+ 一张小几 + 两只茶杯 |
| **窗区** | 西墙偏北 | 雕花木窗（1.7×1.5 m），外开，窗棂是"冰裂纹" |
| **门区** | 东墙正中 | 四扇门（不是一扇门！这是本关特殊设定，见 2.4） |

**关键尺寸**：

- 房间：7.5 × 4.9 × 4.2 m（长 × 宽 × 高）
- 书架：4.2 × 0.38 × 2.6 m，10 格
- 书桌：1.5 × 0.8 × 0.78 m
- 留声机：0.6 × 0.6 × 1.1 m，喇叭直径 0.55 m
- 座钟：0.35 × 0.25 × 0.85 m（落地式，钟摆可见）

| 部位 | 材质 | 颜色 | 备注 |
|---|---|---|---|
| 墙面 | 胡桃木护墙板（下半 1.1 m）+ 米色墙纸（上半） | 深棕 #4a3324 / 米色 #d9c9a8 | 墙纸有细竖条纹 |

| 天花板 | 白色灰泥 + 木梁 | #e8dfce | 木梁深色，2 根 |
| 家具主材 | 胡桃木 + 榉木 | #5b3a20 / #8a6740 | 圆角，黄铜五金 |
| 金属 | 黄铜（台灯、留声机喇叭、抽屉拉手） | #c9974f | 有氧化发黑 |
| 织物 | 藤编（椅子）+ 墨绿丝绒（椅垫）+ 米色棉麻（窗帘） | #6b7a5a | |
| 纸 | 旧纸、宣纸、洋装书 | #e5d6b8 | 边缘发黄 |

**整体色调**：胡桃木深棕 + 墨绿 + 黄铜 + 旧纸米色，饱和度中低，色温偏暖（3200K 左右）。

### 2.3 光照设计（这一关的核心）

| 光源 | 位置 | 参数 | 作用 |
|---|---|---|---|
| **主光：黄昏斜阳** | 从西窗外斜射，太阳还有一点高度 | 方向光，色温 3000K，强度高，暖橙 | 整个关卡的核心机制——**光的角度决定了能看见什么** |
| **补光：台灯** | 书桌上 | 点光源，色温 2700K，暖黄 | 让书桌区成为视觉焦点 |
| **环境光** | 全局 | 低强度偏暖 | 避免暗部死黑 |
| **灰尘粒子** | 光柱内 | 只在夕阳路径上 | 让光"看得见" |

**关键设计**：夕阳的角度**不是固定的**，而是跟着房间朝向走。房间转到某个角度时，夕阳正好斜扫过北墙书架的中段——**只有这个角度，书脊上的烫金字才反光可读**。

这是本关"必须转房间"的根本原因，不是"转到某个方向门才对"，而是"转到某个方向才看得见"。

### 2.4 四扇门的特殊设定

书房东墙不是一扇门，是**四扇小门并排**（每扇 0.55 m 宽，共 2.2 m），像中国老式书房的"书柜门"或"屏风门"。四扇门楣上各刻一个符号：☀ 太阳 / ☾ 月亮 / ✦ 星星 / ⚷ 钥匙。

**为什么是四扇**：因为旋转 90° 后，**东墙会转到南墙位置**——四扇门各自面对不同的外部环境，只有太阳门外面是真正的走廊。玩家要通过镜子看门背面（外侧）的符号来判断。

**门的运作**：
- 四扇门从内侧看，都是普通的木门，看不到符号（符号刻在门楣外侧）
- 东墙外侧走廊里有一面带框的黄铜镜（固定在走廊，不随房间转）
- **通过气窗**（门上方 0.3 m 高的通风口）能看到走廊镜子
- 镜子里映出"当前转到这个位置的门的门楣符号"

**这是本关的观察核心**：玩家必须切到全景视角（或站到气窗前），才能看到镜子里是哪个符号。

### 2.5 谜题链（8 个节拍）

| # | 节拍 | 玩家做什么 | 玩家学到什么 | 时长 |
|---|---|---|---|---|
| 1 | **苏醒** | 第一人称起身，环视房间 | 这是一间老书房 | 20s |
| 2 | **照片** | 捡起地上滑入的拍立得；照片里太阳门对着走廊、门开着；背面写字 | 目标是"让太阳门对着走廊" | 20s |
| 3 | **观察** | 走到东墙，发现四扇门；看不到符号；抬头发现气窗 | 有气窗 → 外面可能有东西 | 30s |
| 4 | **第一次转**（教学） | 按 V 切全景，按 → 转 90°；房间像八音盒一样转；转完发现夕阳的角度变了，书架亮了 | **转房间 = 改变光** | 40s |
| 5 | **读书脊** | 在正确角度，夕阳扫过书架中段的书脊，烫金字显形："日入门，可归" | 谜题答案藏在书脊上 | 60s |
| 6 | **找钥匙** | 光提示"太阳门"；但太阳门锁着；书桌抽屉也锁着；转动留声机喇叭，掉出一把黄铜小钥匙 | 钥匙在声音里（喇叭） | 90s |
| 7 | **开抽屉** | 小钥匙开书桌抽屉 → 里面是太阳门的钥匙 + 一张老照片（爷爷年轻时站在同一扇窗前） | 情感点 | 40s |
| 8 | **转门开门** | 切全景，把太阳门转到东墙正位（朝走廊）；切回第一人称，走近，按 E 开门 | 通关 | 60s |

**总时长**：约 5–7 分钟。

**为什么这个谜题链成立**：
- 第 4 步"转房间 → 光变了"是**教学**，玩家第一次转就明白旋转和光有关系
- 第 5 步"必须转到某个角度才读得出来"是**应用**，用刚学的东西
- 第 6–7 步"钥匙藏在声音里"是**变化**，同样的观察能力用在听觉上
- 第 8 步"把门转到正确位置"是**收束**，回到旋转本身

### 2.6 可选秘密

**镜子里的字**：在错误朝向下（比如月亮门对着走廊），走廊镜子里除了月亮符号，还能看到门楣背面刻的一行小字："吾儿若见此书，当知吾已归家。"——爷爷当年写给自己儿子的。

玩家需要在特定朝向下、站到气窗前、仔细看镜子才能发现。**这个秘密只有真正爱观察的玩家会找到**，但找到的人会记住很久。

### 3.3 光照设计

| 光源 | 位置 | 参数 | 作用 |
|---|---|---|---|
| **主光：最后一缕夕阳** | 从西窗外，几乎水平 | 方向光，色温 2200K，强度中，橙红、影子极长 | 核心机制——这缕光要经过镜子反射 |
| **补光：台灯** | 梳妆台上 | 点光源，2700K，暖黄 | 让梳妆台成为暖色孤岛 |
| **反射光：穿衣镜** | 衣柜门内 | 反射月光 | **这是本关的核心**：月光 → 镜子 → 床底 |
| **环境光** | 全局 | 低强度冷色 | |

**关键设计**：太阳几乎贴地，光从西窗水平射进来，先照到衣柜门内侧的穿衣镜上，再折向床底。**玩家必须把房间转到让"西窗—镜子—床底"三点一线**，床底才会亮起来，露出铁皮饼干盒。

太阳再低一点就落山了——这一关的时间压力是**自然压力**，不是倒计时：光的角度会随太阳下沉微微变化，玩家能感到"再晚就看不到了"。

**为什么这个设计好**：它把"旋转"和"光路"绑在一起，而且玩家能亲眼看到光路一段一段亮起来——反馈非常清晰。

### 3.4 门与暗门

- **东墙门**：普通的卧室门，但它不通向外面，打开是一堵墙（或是走廊的尽头，走不通）。
- **真正的出口**：**大衣柜后面的暗门**。要先把衣柜门打开（月光照到镜子后才看清镜子映出的字），再推动衣柜，露出后面的暗门。

**这个设计的目的**：让玩家不要"找到一扇门就完事"，而是理解"出口藏在家具后面"——这是 70 年代老房子的真实记忆（很多老房子的暗门都在柜子后）。

### 3.6 可选秘密

**录音机**：五斗橱上有一台双卡录音机。按下播放键，放出一段八音盒旋律（妈妈小时候的曲子，和第 3 关是同一首）。旁边还有一盘磁带，标签写着手写的"给未来的我"。

### 4.4 娃娃屋（核心道具）

娃娃屋是这间房的**微缩复制品**，放在矮桌上：

- 尺寸：0.8 × 0.8 × 0.8 m
- 外观：和儿童房一模一样，连墙上的贴纸都一样
- 窗户：和大房间的窗**方向相反**（大房间窗在西，娃娃屋窗在东）
- 底座：有一个可旋转的转盘，**可以单独旋转娃娃屋**
- 内部：小窗、小镜子、小星星灯、小烟囱
- 天花板内侧：一张星图（知识锁）

**玩家怎么玩**：第一人称走到矮桌前，按 E 进入"转盘模式"，用 ← → 旋转娃娃屋；退出后，大房间的旋转仍在全景视角用 ← →。**两个转盘是两个坐标系**，玩家要在大脑里换算。

**这个谜题链的设计逻辑**：
- 第 3–4 步是**观察**：娃娃屋不是装饰，是谜题本体
- 第 5–6 步是**教学**：转大房间 → 转娃娃屋 → 小灯亮，玩家学会"两个转盘要配合"
- 第 7–8 步是**应用**：同样的逻辑，换成月光 → 大灯
- 第 9–10 步是**收束 + 情感**：门开、拉远、发现真相

## 5. 三关的节奏与难度曲线

| | 第 1 关 书房 | 第 2 关 卧室 | 第 3 关 儿童房 |
|---|---|---|---|
| 目标时长 | 5–7 min | 8–10 min | 10–12 min |
| 房间尺寸 | 7.5×4.9×4.2（最小） | 7.0×4.6×4.0（最小） | 8.0×5.2×4.4（最大） |
| 时代 | 1930s | 1970s | 2000s |
| 时间 | 同一个黄昏 · 开始 | 同一个黄昏 · 中段 | 同一个黄昏 · 末尾 → 入夜 |
| 主色 | 深棕 + 墨绿 | 奶油 + 浅粉 | 天蓝 + 星星黄 |
| 关键动词 | **看**（光扫过书脊） | **折**（月光经镜子） | **套**（双层转盘） |
| 旋转次数 | 2–3 | 1–2 | 4–5 |
| 引入的机制 | 旋转改变光 | 镜子反射光 | 双层转盘 |
| 情绪 | 好奇 → 温暖 | 专注 → 心软 | 惊叹 → 释然 |
| 世界记忆点 | 夕阳扫过书架 | 月光流到镜子上 | 镜头拉远发现是娃娃屋 |

**难度曲线设计**：

- 第 1 关**只教一件事**：转房间 = 改变光。全程只有一个概念，5 分钟能通关。
- 第 2 关**加一层中介**：光不是直接照到目标，而是经过镜子。多一个思考步骤，但不超过两个。
- 第 3 关**加一个坐标系**：两个转盘。这是最难的，但放在最后，玩家已经有足够经验。

**为什么不继续加更难的东西**：3 关是"短篇"，玩家的最佳体验是"每关都比上一关多一点点"，不是"每关都难到卡住"。

## 8. 风险与对策

| 风险 | 概率 | 对策 |
|---|---|---|
| 三间房风格差异太大，做出来"不像一个游戏" | 中 | 统一"微缩模型 + 暖色 LUT + 移轴"的后期滤镜，让三关看起来是同一个世界 |
| 第 3 关娃娃屋 image-to-3D 失败 | 中 | 用第 3 关房间的缩放副本 + Lux3D 小家具（已确认的兜底方案） |
| 第 2 关光路太难理解 | 中 | 光路用可见的"光线"可视化；提示系统在第 2 关更早介入 |
| 第 3 关两个转盘太多，玩家混乱 | 高 | 进入转盘模式时，大房间静止、只显示娃娃屋的转盘 UI；退出后才恢复大房间旋转 |
| 134 个资产做不完 | 高 | 按 P0/P1/P2 分级，先保 P0；P2 全部砍掉也能玩 |
| SpatialGen 生成不出"1930s 中国"的感觉 | 中 | prompt 加中文关键词；失败就用 Lux3D 家具 + 手搭房间壳，SpatialGen 只做墙地材质 |

## 9. 已确认的 5 个设定（2026-11-04）

| 问题 | 决定 |
|---|---|
| 三关顺序 | **书房 → 卧室 → 儿童房**（年代由远及近） |
| 季节与天气 | **同一个黄昏**：三关是同一天日落前的十几分钟，太阳越来越低 |
| 第 2 关情感浓度 | **更克制**：铁皮盒里只有钥匙、玻璃弹珠、写着一个日期的纸片，不写信、不给完整照片 |
| 第 3 关入夜 | **玩家手动拉灯绳**：亲手让太阳落山，是全片情感转折点 |
| 窗外 | **三关都是同一棵树**，只随年代变化：细枝 → 长到窗框 → 粗壮半秃 |

**这五个决定共同指向一件事**：三关不是三个关卡，是同一个黄昏、同一扇窗、同一棵树、同一个人的三段记忆。
